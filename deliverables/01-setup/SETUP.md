# 01 – Setup

About 30 minutes the first time. Windows, macOS and Linux.

## 1. Prerequisites

| Tool | Version | Check |
|---|---|---|
| Node.js | 20 LTS+ | `node -v` |
| Java JDK | 17+ (Android Studio's bundled `jbr` works) | `java -version`, `echo $env:JAVA_HOME` |
| Android Studio + SDK | current, API 30+ | `adb version`, `echo $env:ANDROID_HOME` |
| Instagram | Play Store, on the emulator | – |

Fastest check of everything: `npm run setup` (also creates `.env` and `.gitignore` if missing).

### Windows: JAVA_HOME and ANDROID_HOME (once, then open a new terminal)

~~~powershell
$jdk = "C:\Program Files\Android\Android Studio\jbr"          # or your JDK 17 folder
[Environment]::SetEnvironmentVariable("JAVA_HOME", $jdk, "User")
[Environment]::SetEnvironmentVariable("ANDROID_HOME", "$env:LOCALAPPDATA\Android\Sdk", "User")
$p = [Environment]::GetEnvironmentVariable("Path", "User")
[Environment]::SetEnvironmentVariable("Path", "$p;$jdk\bin;$env:LOCALAPPDATA\Android\Sdk\platform-tools", "User")
~~~

## 2. Install

~~~bash
npm install
npm run appium:driver       # UiAutomator2 driver (skip if already installed)
npm run setup               # prerequisites + .env/.gitignore
npm run appium:doctor       # required checks must pass; ffmpeg / gstreamer / bundletool are optional
~~~

## 3. Emulator

1. Android Studio → Device Manager → a device **with Google Play** (e.g. Pixel 6, API 33/34).
2. Start it; `npm run devices` must list it (e.g. `emulator-5554`). Other name → `DEVICE_NAME` in `.env`.
3. Gesture or 3-button navigation both work.

## 4. Instagram on the emulator

Install from the Play Store, log in **once by hand** with the test account (accept terms, dismiss tips), log out again.
Use a **dedicated test account** – see 05-test-data.

## 5. Credentials

Fill `.env` (created by `npm run setup`, or copy `.env.example`):

~~~powershell
Copy-Item .env.example .env; notepad .env
~~~

## 6. First run

~~~bash
npm run check               # all files present and valid
npm run test:valid          # one test, 1–2 min
npm run dashboard           # opens the result
~~~

## Troubleshooting

| Symptom | Fix |
|---|---|
| `JAVA_HOME environment variable is NOT set` | set it (above), open a **new** terminal |
| `Could not find a connected Android device` | emulator not running / not in `npm run devices`; check `DEVICE_NAME` |
| `ECONNREFUSED 127.0.0.1:4723` | another Appium is running on 4723 – close it |
| `uiautomator2 driver not installed` | `npm run appium:driver` |
| first session very slow | first run installs the UiAutomator2 server – rerun |
| `Cannot find path … .env.example` | dot-files got lost while copying – `npm run setup` recreates it |
| "App is not on any known screen" | dashboard → failed step → page source (XML); see 04-locators |
| Login asks for a code / suspicious login | Instagram security check – complete it by hand on the emulator |
