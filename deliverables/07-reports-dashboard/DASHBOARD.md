# 07 – Dashboard & reports

~~~bash
npm run dashboard          # rebuild + open reports/dashboard/index.html
~~~

Rebuilt automatically after every run. Static page – open from disk, zip `reports/` to share, or publish it from CI.

## Overview

| Part | Shows |
|---|---|
| KPI tiles | last run status, last run tests passed/total, pass rate (last 10 runs), average duration, runs kept |
| Pass / fail per run | one bar per run – click to open the run |
| Test stability | each test's last 10 results, pass rate, average time, last failure; **flaky** = mixed results |
| Runs | id + label, status, start, duration, scope, tests ✓/✗, steps ✓/✗, device |

## Run page

- Header: status, totals, start/finish, duration, exact command, device, app, machine, exit code.
- Files: wdio worker logs, `appium.log`, JUnit XML of that run.
- Toolbar: All / Failed only, search, expand / collapse all.
- Per test: status, steps, duration, error + stack trace (failed tests open automatically).
- **Per step:** screenshot (click to enlarge, ← → to step, Esc), passed/failed, duration, time,
  **step log** (taps, typing, gestures with selectors + timings, console lines), and for failed steps the
  **error, stack trace and page source (XML)**. `auto` = added by the framework (popup, final screen, failure outside a step).

## Files

~~~
reports/
├─ dashboard/                index.html + data.js
└─ runs/<run id>/
   ├─ run.json               run metadata
   ├─ logs/                  wdio-*.log, appium.log
   ├─ junit/                 results-*.xml
   └─ <suite>/
      ├─ suite.json          tests + steps
      └─ <test>/NN-step.png  (+ NN-step.xml for failed steps)
~~~

History: newest 30 runs (`KEEP_RUNS`). Retries show as `<suite>-attempt-2`. Interrupted runs show as **incomplete**.

## Other reports

| Report | Where | Use |
|---|---|---|
| JUnit XML | `reports/runs/<id>/junit/` | CI test tab, Jira/Xray/TestRail import |
| Allure | `npm run report:allure` | alternative report of the last run |

## Reporting a failure

Send the run id, the test name and – from the failed step – the screenshot, the error and the XML file.
