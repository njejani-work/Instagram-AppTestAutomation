# instagram-appium-tests – handover

Automated UI tests for the **Instagram Android app** with WebdriverIO + Appium (UiAutomator2) + Mocha, Page Object Model.
Every step is recorded with a screenshot, duration, log and – on failure – error, stack trace and page source; a dashboard keeps the run history.

## Start here

~~~bash
npm install
npm run setup               # prerequisites + .env / .gitignore
npm run check               # project files present and valid
npm run test:smoke          # P1: login + login→logout
npm run dashboard           # results
~~~
